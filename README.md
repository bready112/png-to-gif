# PNG to GIF 변환기 사용 설명서
# 프로그램 소개
PNG 이미지들을 애니메이션 GIF로 변환하는 프로그램입니다

# 기본 사용법
pngtogif.exe 파일을 원하는 위치에 복사\
PNG 파일들을 준비 (같은 폴더에 모아두기)

# 프로그램 실행 방법:
더블클릭으로 실행 (기본 설정 사용)\
또는 명령 프롬프트(cmd)에서 옵션과 함께 실행\
명령줄 옵션\
-i : PNG 파일들이 있는 폴더 (생략시 exe 폴더 사용)\
-o : 저장할 GIF 파일명 (생략시 output.gif 사용)\
-d : 프레임 간 시간(ms) (생략시 42ms = 24fps)\
프레임 속도 설정\
자주 사용하는 프레임 속도:

24fps: -d 42 (기본값)\
30fps: -d 33\
60fps: -d 17\
사용 예시


# 주의사항
GIF 파일은 항상 exe 옆의 GIF 폴더에 저장됨\
파일명 순서대로 프레임이 만들어짐\
모든 PNG는 첫 번째 이미지 크기로 자동 조정됨\
실행 폴더에 쓰기 권한 필요 (GIF 폴더 생성)


# 문제해결
"액세스 거부" → 관리자 권한으로 실행\
"바이러스 검사" 경고 → "더 많은 정보" → "실행" 클릭\
PNG 파일을 찾을 수 없음 → -i 옵션으로 올바른 폴더 지정


# 1. 사용 책임
이 프로그램은 "있는 그대로" 제공되며, 어떠한 보증도 제공하지 않습니다.
프로그램 사용으로 인한 데이터 손실이나 시스템 문제에 대해 책임지지 않습니다.
사용자는 중요한 파일의 백업을 유지할 책임이 있습니다.
# 2. 저작권 및 라이선스
변환하려는 PNG 파일에 대한 사용 권한이 있는지 확인하세요.
저작권이 있는 이미지를 무단으로 사용하지 마세요.
생성된 GIF의 사용 권한은 원본 PNG 파일의 라이선스를 따릅니다.
# 3. 시스템 요구사항
Windows 운영체제에서만 실행 가능합니다.
실행 폴더에 쓰기 권한이 필요합니다.
최소 메모리 요구사항: 처리하는 이미지 크기에 따라 다름
# 4. 데이터 안전
원본 PNG 파일은 수정되지 않습니다.
프로그램은 자동으로 GIF 폴더를 생성합니다.
같은 이름의 GIF 파일이 있으면 덮어쓰기 됩니다.
# 5. 보안 관련
신뢰할 수 있는 출처에서 받은 exe 파일만 실행하세요.
Windows 보안 경고가 표시될 수 있습니다.
관리자 권한이 필요할 수 있습니다.
# 6. 성능 고려사항
대용량 PNG 파일은 처리 시간이 길어질 수 있습니다.
많은 수의 프레임은 GIF 파일 크기를 크게 증가시킬 수 있습니다.
시스템 리소스 사용량이 증가할 수 있습니다.
# 7. 오류 발생 시
오류 메시지를 확인하고 적절한 조치를 취하세요.
필요한 경우 관리자 권한으로 실행하세요.
문제가 지속되면 프로그램을 재설치하세요.
# 8. 제한사항
GIF 형식의 제한으로 인해 화질이 저하될 수 있습니다.
모든 PNG 파일 형식을 지원하지 않을 수 있습니다.
최대 파일 크기와 프레임 수에 제한이 있을 수 있습니다.
